# Changelog

All notable changes to Chronos Timer will be documented in this file.

## 1.0.0

### Added

- Configurable status effect HUD
- Timer display mode
- Progress-bar display mode
- Top, bottom and side attachments
- Horizontal and vertical layouts
- Left and right screen positioning
- Top, center and bottom anchoring
- Configurable HUD opacity
- Roman numeral effect levels
- Warning color during the last 10 seconds
- Support for ambient status effects
- Nythral Library integration

### Changed

- Replaced the vanilla status effect HUD
- Improved progress-bar directions for top, bottom and side attachments
- Added separate timer text positioning for top, bottom and side attachments
